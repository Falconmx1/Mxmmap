# Mxmmap

Herramienta ligera para analizar, mapear y visualizar el uso de memoria RAM en Windows.

## ✨ Características
- Listado de procesos activos y su consumo de memoria
- Mapeo de regiones de memoria (VirtualQuery / ReadProcessMemory)
- Inspección de handles y módulos cargados
- Interfaz rápida y minimalista
- Exportación de reportes

## 🛠️ Requisitos
- Windows 10/11
- Compilador compatible (MSVC / MinGW)
- Privilegios de administrador (para acceso a procesos)
